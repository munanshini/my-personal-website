## 已确认范围

参考 GitHub Copilot 页面清晰的层级、留白与克制的深色视觉，保留已有项目文案和品牌橙红色。不复制产品截图，不改写项目事实。本轮仅本地预览，不推送部署。

## 实现

- 首次访问默认深色，保留用户保存的浅色或深色偏好；启动脚本与 React 初始化保持一致。
- 全站内容最大宽度统一为 1240px，统一页面标题、章节标题和正文样式，使用适合中文的字体回退及行高。
- 首页改为文字与人物分区布局；人物保持等比完整展示，背景纯色。
- WORK 保留左标题右简介，项目卡片区分公司、项目内容和结果。
- 详情页增加工作流程概览、桌面固定章节目录与移动端折叠目录；关键决策按问题、判断、取舍纵向阅读，原章节顺序与文案保留。
- WORDS、NOW、CONTACT 同步标题、宽度、间距与卡片规范；NOW 去除固定列表高度；联系页优化手机邮箱布局。
- 减弱导航光效，避免出现双选中胶囊；补充统一页脚导航；保留 PageTransition。
- 修复直接打开带章节 hash 的详情链接时被初始化滚动重置的问题。
