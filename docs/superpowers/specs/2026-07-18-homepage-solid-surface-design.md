# 首页纯色与导航悬停细节设计

## 目标

让首页从带有光斑和渐变叠层的视觉表现，收敛为更稳定的纯色主题底与右侧人物构图；同时让桌面一级导航在未选中状态下拥有清晰、克制的 hover 反馈。

## 范围

### 首屏

- 删除鼠标移动触发的人物照片光斑层及其动画、canvas 和事件监听。
- 删除 SideRays 光线效果。
- 删除首屏人物图层和前景遮罩中的所有 CSS 渐变。
- 首屏底色直接使用主题语义色 `bg-paper`：浅色模式为米白，深色模式为深黑。
- 人物保留在右侧，继续使用当前照片与移动端构图；不新增图片处理或新的视觉素材。

### 桌面一级导航

- 当前页面继续使用实体填充的选中 pill。
- 非当前页面在 hover 或键盘聚焦时，显示与当前 pill 相同尺寸、圆角的细描边。
- hover 不改变导航容器尺寸，不移动当前选中 pill，不改变点击后的路由和选中逻辑。
- 移动端纵向菜单不在本次范围内调整。

## 不在范围内

- 不改首页文案、人物素材、首屏排版位置或自定义鼠标箭头。
- 不改其他一级页面、Open to Work、AI 助手或主题切换。
- 不新增二级页面。

## 验收标准

- 鼠标在首屏移动时，人物图层不再随鼠标出现局部变亮或光斑。
- 首屏中不存在 SideRays、线性渐变或径向渐变遮罩。
- 浅色和深色模式下，首页底色均为对应主题的纯色。
- 桌面未选中的导航项 hover 时只出现同尺寸描边；点击后仍显示实体选中态并完成页面切换。
- 现有测试、生产构建和桌面/移动端首页检查通过。
